### 🎥 About

A **modern, SaaS-style login page** built around a full-screen looping video background and a clean glassmorphic login card. Designed to look and feel like a real product's auth screen — the kind you'd see on a modern startup landing page — with a "Continue with Google" option and a minimal, cinematic aesthetic.

### ✨ Features

- 🎬 Full-screen looping video background
- 🪟 Glassmorphic login card with soft blur
- 🔐 Login + "Sign in with Google" UI
- 📱 Responsive layout
- 🎯 Clean, product-style copywriting and layout
